# Офлайн-игры для Android

## Орбита 2.0 — 16 игр

Скачайте `Orbita-v2.apk` (или `Orbita-offline.apk`, это одна сборка).

Новое: 3D-гонки Орбита GT, 3D-паркур Выше неба, Стикман: Перехват на турниках, Кейс-лаборатория (33 облика, 3 кейса, прокрутка, продажа, тренировка), Крылья, Пинг-понг, Астероидный пояс, Тетрис, Четыре в ряд и Пятнашки.

Сохранены 2048, Змейка, Арканоид, Неоновый рывок, Найди пару и Сапёр. Добавлены избранное и категории 3D/симуляторы. Облики машин и персонажей из кейсов применяются в гонках, паркуре и стикмане. Только игровые монеты, без реальных платежей.

Устанавливайте поверх старой Орбиты, не удаляя её: пакет, подпись и локальное хранилище сохранены. Подписи и совместимость пакетов проверены.

## Прорыв — отдельный 3D-шутер

`Breach-offline.apk`: боты3×3, бомба, оружие, скины и кейсы. Эта сборка не изменена.

`Offline-games.zip` содержит Орбиту2.0 и Прорыв одним архивом.

Нужны Android8+ и актуальный Android System WebView; для 3D — WebGL. Все ресурсы встроены, интернет для игры не нужен. Откройте APK на телефоне и разрешите установку для приложения, из которого открыт файл. Подписи локальные для прямой установки. Игровые и браузерные проверки пройдены, но на физическом Android не запускалось. Контрольные суммы — в `SHA256SUMS.txt`.
