# Офлайн-игры для Android

## Орбита 5.0 — 33 игры разных жанров

[Скачать Орбита-v5.apk](https://raw.githubusercontent.com/nuralisalimov03-netizen/hhhhhg/downloads/offline-games-v1/Orbita-v5.apk)

Добавлено десять самостоятельных игр:

- «Оборона ядра» — защита базы с башнями, улучшениями и восемью волнами.
- «Тихая рыбалка» — заброс, подсечка и вываживание с натяжением лески.
- «Бильярд: точный удар» — 3D-тренировка с настоящими столкновениями, бортами и лузами.
- «Лис и затерянный остров» — три уровня с ключами, дверями, монетами и противниками.
- «Кухня на скорость» — приготовление рецептов и обслуживание заказов за 90 секунд.
- «Дрон-курьер» — свободный 3D-полёт, три доставки, препятствия и зарядные площадки.
- «Судоку» — два уровня сложности, заметки и подсказки; единственное решение.
- «Складские истории» — десять решаемых уровней с ящиками и отменой ходов.
- «Ритм-свет» — три оригинальных синтезированных трека и четыре дорожки.
- «Распутай» — восемь разных схем с перетаскиванием узлов.

Фильтр «Новинки · 10» показывает эту подборку. Прежние 23 игры сохранены, в том числе метро-раннер, гонки с тремя трассами, лёгкий/сложный паркур, морской бой, крестики-нолики, кейсы и аркады. Все девять 3D-игр работают на весь экран. Новые 2D-игры имеют общую паузу и явное возобновление после сворачивания.

Устанавливайте поверх предыдущей «Орбиты», без удаления: пакет, ключ подписи и адрес локального хранилища сохранены. Для работы нужен Android 8.0+; для 3D — Android System WebView с WebGL. В настройках доступно качество «Скорость». Все ресурсы внутри APK; рекламы, регистрации и доступа к интернету нет.
