# Офлайн-игры для Android

Готовые APK для прямой установки на Android 8.0 и новее.

- `Orbita-offline.apk`: Орбита — сборник шести мини-игр.
- `Breach-offline.apk`: Прорыв — 3D-шутер с ботами, бомбой, скинами и кейсами.
- `Offline-games.zip`: обе игры одним архивом.

Откройте APK на телефоне и разрешите установку для приложения, из которого открыт файл. Для шутера нужен актуальный Android System WebView с поддержкой WebGL. Сборки подписаны сертификатами разработки; на физическом Android не тестировались. SHA-256 приведены в `SHA256SUMS.txt`.
