# Офлайн-игры для Android — версии 2.0

## Прорыв 2.0 — тактический 3D-шутер

Скачайте `Breach-v2.apk` или `Breach-offline.apk` — это одна сборка.

Обновлено управление: движение и стрельба с наведением двумя большими пальцами; дополнительные касания не перехватывают джойстик; пауза очищает нажатия. Первый щелчок захвата мыши не стреляет, Escape обрабатывается один раз. Прицел и приседание работают нажатием или удержанием; регулируются размер кнопок, зона покоя, чувствительность обзора и прицела.

Интерфейс: подписанные кнопки, обучение перед первым боем, постоянная задача с расстоянием до цели, понятные здоровье/броня/патроны, прогресс перезарядки. Боты стреляют очередями с паузами, отдача возвращается к выбранному направлению. Сохранены бои 3×3, бомба, оружие, скины и кейсы. Только игровые монеты, без реальных платежей.

## Орбита 2.0 — сборник 16 игр

Скачайте `Orbita-v2.apk` или `Orbita-offline.apk` — это одна сборка.

3D-гонки, 3D-паркур, стикман на турниках, симулятор кейсов с 33 обликами, Крылья, Пинг-понг, Астероидный пояс, Тетрис, Четыре в ряд, Пятнашки и прежние шесть мини-игр. Избранное, категории и локальные рекорды.

## Установка и сохранения

`Offline-games.zip` содержит обе игры версии 2.0. Нужны Android 8.0+ и актуальный Android System WebView с поддержкой WebGL. Все игровые ресурсы включены в APK; интернет для игры не нужен.

Откройте APK на телефоне и разрешите установку для приложения, из которого открыт файл. Устанавливайте поверх прежних версий, не удаляя их: пакеты, сертификаты подписи и адреса локального хранилища сохранены, номера версий увеличены. Подписи и совместимость пакетов проверены.

Игровые и браузерные проверки пройдены. На физическом Android в текущей среде не запускалось. Сборки подписаны локальными сертификатами разработки для прямой установки. Контрольные суммы находятся в `SHA256SUMS.txt`.
