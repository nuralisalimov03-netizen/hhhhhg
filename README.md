# Weqrom 1.2

[**Скачать готовый Weqrom-1.2.apk — 379 МБ**](https://github.com/nuralisalimov03-netizen/hhhhhg/raw/refs/heads/downloads/offline-games-v1/Weqrom-1.2.apk?download=1) · [Инструкция и проверки](weqrom/README.md)

Скачайте APK на телефон и установите **поверх Weqrom 1.1 или 1.0**. Ключ подписи сохранён; удалять приложение не требуется. Android 8+ ARM64.

Версия 1.2 исправляет ошибку раннего запуска: до завершения создания Application новый модуль мог прерываться, поэтому приветствие и меню настроек из 1.1 не появлялись. Добавлен регрессионный тест именно на эту фазу запуска. По умолчанию обычная красная палитра сохраняется без включения дополнительного перекрашивания.

Включены приветствие Weqrom со сменой «Привет» на 13 языках, выбор русского/белорусского/английского языка панелей, Беларусь по умолчанию, 19 стран, светлая/тёмная/системная тема, шесть цветов акцентов и лайков, уменьшение анимаций и виброотклик. Новые панели используют обычные элементы Android; анимации останавливаются после закрытия или сворачивания.

**Где менять регион:** Профиль → ☰ → Настройки и конфиденциальность → Настройки Weqrom → Регион мода. В приветствии есть «Настроить перед стартом». Этот регион меняет данные страны SIM/оператора для клиента; страна аккаунта и IP остаются отдельными параметрами. Доступность TikTok в России и скорость на конкретном телефоне не проверены.

# Офлайн-игры для Android

## Орбита 6.0 — 45 игр

[Скачать Orbita-v6.apk](https://raw.githubusercontent.com/nuralisalimov03-netizen/hhhhhg/downloads/offline-games-v1/Orbita-v6.apk)

Двенадцать новых игр с разными правилами:

- «Отряд: рубеж» — пошаговая тактика, два бойца, укрытия и три миссии.
- «Маленькая ферма» — четырнадцать игровых дней, посадки, урожай, заказы и улучшения.
- «Детективное бюро» — три оригинальных дела с уликами, показаниями и вердиктами.
- «Косынка» — пасьянс с переносом стопок, отменой, подсказками и решаемыми учебными раскладами.
- «Домино: дуэль» — классические кости, цепочка, базар и компьютерный соперник.
- «Реверси» — стратегическая дуэль с двумя уровнями бота.
- «Словодел» — русские слова из букв, десять наборов и подсказки.
- «Пиксельные истории» — японские кроссворды с картинками, заполнением, крестиками и отменой.
- «Баскетбол: дуга» — 3D-броски с физикой мяча, кольца и щита.
- «Пинбол: импульс» — пружина, бамперы, управляемые лапки и три шара.
- «Лунная посадка» — тяга, инерция, топливо и три посадочных маршрута.
- «Городской диспетчер» — два перекрёстка, фазы светофоров, очереди и пропуск машин.

Фильтр «Новинки · 12» показывает новую подборку. Раздел «Настольные» объединяет карты, домино, реверси, крестики-нолики, морской бой и четыре в ряд; «Приключения» открывает детектив. Все прежние 33 игры доступны. Десять 3D-игр используют полный экран; есть качество графики «Скорость».

Устанавливайте поверх старой «Орбиты» без удаления. Пакет приложения, ключ подписи и адрес локального хранилища сохранены. Требуется Android 8.0+; для 3D нужен Android System WebView с WebGL. Все игры входят в APK, интернет, регистрация и реклама не нужны.
