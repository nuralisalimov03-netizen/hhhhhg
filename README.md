# Офлайн-игры для Android

## Орбита 4.0 — 23 игры

[Скачать Орбита-v4.apk](https://raw.githubusercontent.com/nuralisalimov03-netizen/hhhhhg/downloads/offline-games-v1/Orbita-v4.apk)

Добавлены «Метро-рывок» (3D-раннер между поездами с прыжками, подкатом, монетами, магнитом и защитной доской), «Крестики-нолики» (два уровня бота и игра вдвоём), «Морской бой» и «Башня баланса».

В гонках доступны три разные трассы: Лазурный берег, Красный каньон и Неоновый город. В паркуре — лёгкий и сложный маршруты. Все семь 3D-игр работают на весь экран с крупными кнопками и общим меню паузы. Остальные игры, рекорды, избранное и коллекция кейсов сохранены.

Устанавливайте поверх предыдущей «Орбиты», без удаления. Для работы нужен Android 8.0+ и Android System WebView с WebGL. В настройках есть режим графики «Скорость». Все ресурсы внутри APK, реклама, регистрация и доступ к интернету отсутствуют.
