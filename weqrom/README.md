# Weqrom 1.1

![Значок Weqrom](icon.png)

Производная предоставленной пользователем сборки **TikTok You 5.0 / TikTok 47.4.3**. Исходные данные и границы проверки основы — в [отчёте TikTok You](../TikTok-You-README.md). Weqrom — отдельное приложение с пакетом TikTok `com.zhiliaoapp.musically`; в Chits Market оно не включено.

## Скачать и установить

[**Скачать Weqrom-1.1-Builder.zip**](https://raw.githubusercontent.com/nuralisalimov03-netizen/hhhhhg/downloads/offline-games-v1/Weqrom-1.1-Builder.zip)

1. Распакуйте ZIP на компьютере и откройте `index.html` в современном браузере, например Яндекс Браузере.
2. Выберите **первоначальный** `TikTok_You-5.0.47.4.3.apk`, который вы загрузили в GitHub Release. Нужен именно исходник, а не ранее полученный Weqrom. Имя может отличаться; проверяются точные размер и SHA-256 содержимого.
3. Скачайте полученный **Weqrom.apk**, перенесите на телефон и установите.

Это локальное восстановление точных байтов уже собранного и подписанного APK. Python, расширения и отправка APK на сервер не нужны. SHA-256 входа и результата проверяются. Исходный файл остаётся без изменений.

**Weqrom 1.1 устанавливается поверх Weqrom 1.0:** пакет и закрытый ключ подписи сохранены; versionCode повышен до 2024704031. Удалять 1.0 не требуется. При переходе с другого TikTok/TikTok You Android не примет несовпадающую подпись: прежде чем удалять старую сборку, сохраните локальные черновики и другие нужные данные.

Требуется **Android 8.0+ ARM64**. Исходный динамический мод уже использовал DEX038; новая сборка явно указывает соответствующий minSdk 26. TargetSdk 36 сохранён.

Готовый большой APK находится в среде: `/workspace/hhhhhg/weqrom/dist/Weqrom.apk`, около 379 МБ. Он не добавляется в обычный Git из-за ограничения размера файла. Небольшой публичный ZIP восстанавливает тот же APK из имеющегося у пользователя исходника. [Точные размеры и отчёт](build-report.json) · [SHA-256 файлов](../Weqrom-SHA256SUMS.txt).

## Где менять регион

**Профиль → ☰ → Настройки и конфиденциальность → Настройки Weqrom → Регион мода.** Пункт встроен в существующее меню настроек исходного клиента. При первом приветствии есть кнопка «Настроить перед стартом».

Беларусь (`BY`, оператор 25701/A1) выбирается при первом запуске 1.1, включая обновление с 1.0. Это однократная миграция; последующий ручной выбор сохраняется. Доступны 19 стран из настоящего списка регионов основы. Применение использует существующий setter мода и его хуки `getSimCountryIso`, `getNetworkCountryIso`, страны и имени оператора.

**Это не перенос страны аккаунта TikTok и не смена IP, GPS или самой SIM.** Сервер может учитывать страну регистрации, соединение и другие данные, а приложение — кэшировать ранее прочитанные значения. Поэтому Россия в разделе страны аккаунта не доказывает, что выбранный модом `BY` не сохранился. Полная работа рекомендаций для Беларуси требует проверки на телефоне; гарантий обхода ограничений нет.

## Новое в интерфейсе

- Старое окно TikTok You заменено собственным приветствием: 13 плавно сменяющихся приветствий, «Нажмите, чтобы продолжить», выбор языка, «Наслаждайтесь Weqrom» и закрытие окна к исходному клиенту.
- Панели полностью переведены на русский, белорусский и английский. Язык ленты меняется отдельно в TikTok.
- Светлая, тёмная и системная темы используют найденный штатный механизм TikTok. Смена темы пересоздаёт Activity, поэтому открытая панель настроек может закрыться.
- Красный, синий, лаймовый, фиолетовый, оранжевый и розовый **акцент и лайки**. Основа перекрашивает общую палитру, включая кнопки; независимый цвет только сердечек не заявляется.
- Уменьшение анимаций, необязательный виброотклик, повтор приветствия и доступ к дополнительным функциям исходного мода.

Новые панели — обычные элементы Android без WebView, фонового сервиса, сетевых запросов или покадрового обхода ленты. Анимации работают только пока панель видима; при сворачивании останавливаются. Мастер сохраняет текущий шаг при обычном Home → возврат. Эти решения ограничивают добавленную нагрузку, но измерений FPS, батареи и скорости на телефоне нет.

Автоматические обновления и статистика исходного мода выключаются при миграции. Исходные дополнительные настройки сохранены, с сохранением атрибуции. Установка APK обновляет Weqrom; загрузчик отделяет совместимость собственных модулей от ранее скачанных модулей основы, сохраняя проверки хешей, подписей и механизм отката.

## Проверки

Пройдены компиляция Java и DEX, проверяемые патчи конкретных исходных методов, тесты AXML/ресурсов/ZIP, JVM-тесты настоящего кода миграции региона и темы с изолированными заменами Android API. Эти тесты проверяют сохранение выбора, однократность миграции, вызовы правильных setter, обработку ошибок темы и завершение приветствия. Они не запускают TikTok.

Итоговый APK проверяется AAPT, ZIP/CRC, zipalign и apksigner. Браузерный сборщик тестируется на настоящем большом APK с точным совпадением SHA-256 и отсутствием внешних запросов. Управляемый Chromium запрещает `file://`, поэтому браузерные тесты используют собственный loopback HTTP; HTML остаётся самодостаточным для обычного локального открытия.

**Android-приложение в облаке не запускалось.** Вход, рекомендации, видимость пункта на конкретном телефоне, фактическая смена темы/цветов/региона и работа в России не подтверждены выполнением приложения. Новая сборка использует стороннюю основу; проверка подписи и хешей не является проверкой её безопасности. Проверки авторизации и целостности исходника не отключались.

## Сборка для разработчика

```sh
bash chits-market/tools/setup-android.sh
python3 -m pip install -r weqrom/requirements.txt
python3 weqrom/tools/setup_mod_tools.py
python3 weqrom/tools/build.py --source /path/to/TikTok_You-5.0.47.4.3.apk
python3 weqrom/tools/make_web_builder.py \
  --source /path/to/TikTok_You-5.0.47.4.3.apk \
  --target weqrom/dist/Weqrom.apk \
  --output-dir weqrom/dist/builder \
  --zip weqrom/dist/Weqrom-Builder.zip
python3 -m unittest discover -s weqrom/tests -v
```

Официальный JADX 1.5.3 закреплён по SHA-256; его библиотеки предоставляют Smali CLI. Компилируемые заглушки API в `integration/stubs` служат только для компиляции и **не включаются в APK**. Все исходные пути и сигнатуры сверяются до применения патчей. Контрольные суммы модуля в его встроенном манифесте обновляются на фактический новый DEX; проверка загрузчиком сохраняется.

Закрытый ключ и пароль находятся только в `/workspace/.weqrom-signing`; их нельзя печатать, публиковать или включать в ZIP. Для совместимых обновлений нужен тот же ключ. Не добавляйте большой входной APK, `dist`, `build` или приватные данные в Git.

Тест настоящего браузерного восстановления запускается отдельно с `WEQROM_ACTUAL_SOURCE`, `WEQROM_ACTUAL_TARGET`: `python3 weqrom/tests/test_web_builder.py ActualBrowserTests`. Для него нужны Playwright, Chromium и разрешённый локальный сокет.
