# Weqrom 1.0

![Weqrom icon](icon.png)

Weqrom — пользовательский ребрендинг предоставленной сборки **TikTok You 5.0 / TikTok 47.4.3**. Это производная стороннего клиента, а не новый сервис TikTok и не приложение, написанное с нуля. Происхождение основы и ограничения проверки описаны в [отчёте TikTok You](../TikTok-You-README.md).

По выбору пользователя Weqrom **заменяет TikTok**, сохраняя пакет `com.zhiliaoapp.musically`. В Chits Market он не включён.

## Как получить APK

[Скачать Weqrom-Builder.zip](https://raw.githubusercontent.com/nuralisalimov03-netizen/hhhhhg/downloads/offline-games-v1/Weqrom-Builder.zip) — около 11 МБ.

1. Распакуйте архив и откройте `index.html` в современном браузере компьютера, например Яндекс Браузере.
2. Выберите ранее скачанный `TikTok_You-5.0.47.4.3.apk` (379025632 байта). Имя файла может отличаться, но содержимое должно точно совпасть с исходником.
3. Нажмите кнопку сборки и скачайте полученный **Weqrom.apk**. Перенесите его на Android-телефон.

Python, установка расширений и передача APK на сервер для этого не нужны. HTML содержит весь код и данные локально; проверяются SHA-256 исходного файла и результата. Браузер восстанавливает **точные байты уже подписанной сборки**, а не подписывает APK новым случайным ключом. Исходный файл не изменяется.

Сам готовый APK также находится в подготовленной среде: `/workspace/hhhhhg/weqrom/dist/Weqrom.apk`. Его размер — **379087023 байта**. Большой бинарный файл не добавлен в обычный Git; публичный небольшой ZIP — способ получить тот же результат из имеющегося исходника, пока загрузка большого GitHub Release через API заблокирована сетью среды.

## Установка вместо TikTok

Weqrom подписан новым отдельным ключом. Установить его поверх TikTok/TikTok You с другим ключом Android не позволит. **Сохраните локальные черновики и другие нужные локальные данные перед удалением старой сборки.** Затем пользователь самостоятельно устанавливает Weqrom и при необходимости заново входит в аккаунт TikTok. Сборщик не удаляет приложения и не запрашивает пароль или токены аккаунта.

APK содержит только `arm64-v8a`. Манифест сохраняет minSdk 23 и targetSdk 36 исходника; фактическая работа на конкретном устройстве требует проверки. При создании новой подписи старая некорректная v1-метаинформация основы удалена и сформирована заново: итоговый APK проходит обычную полную проверку v1/v2/v3 без ограничения диапазона SDK или отключения проверки.

## Что изменено

- Название приложения и все семь launcher-алиасов отображаются как **Weqrom**.
- Создан оригинальный чёрно-зелёный значок W: пять PNG-размеров и семь XML-вариантов ярлыков.
- Единственное точное имя `TikTok` в глобальном пуле ресурсов заменено на `Weqrom` без изменения длины или индексов.
- Добавлен `assets/weqrom/NOTICE.txt` с указанием исходной модификации.
- Выполнены выравнивание и подпись отдельным ключом Weqrom.

**DEX-код и все нативные `.so` библиотеки совпадают с исходником по SHA-256.** Новые механизмы входа, смены региона, обхода ограничений или серверы не добавлялись. Существующий модуль TikTok You и его атрибуция сохранены; его функции не проверены выполнением приложения.

## Проверки и ограничения

Пройдены: разбор манифеста настоящим AAPT, правильные имена всех launcher-алиасов, ZIP/CRC, подписи v1/v2/v3, выравнивание, сравнение всех DEX/SO, тесты AXML/UTF-пулов и ZIP-перепаковки. Браузерный сборщик восстановил настоящий 379-МБ APK с точным ожидаемым SHA-256; при тесте не было внешних запросов. Проверка браузера выполнена через собственный loopback HTTP: управляемая браузерная среда блокирует `file://`. Для обычного офлайн-открытия HTML сделан самодостаточным, без загрузки локальных/сетевых зависимостей.

Приложение не запускалось на Android. В облачной машине x86_64 нет KVM и подходящей проверенной ARM64-эмуляции, поэтому **запуск, вход, лента, модуль региона, работа в России и безопасность сторонней основы не подтверждены**. Новая подпись также может влиять на проверки целостности и некоторые способы входа исходного приложения. Проверки защиты исходного клиента не отключались.

## Повторная сборка

На подготовленном Linux-хосте:

```sh
bash chits-market/tools/setup-android.sh
python3 -m pip install -r weqrom/requirements.txt
python3 weqrom/tools/build.py --source /path/to/TikTok_You-5.0.47.4.3.apk
python3 weqrom/tools/make_web_builder.py \
  --source /path/to/TikTok_You-5.0.47.4.3.apk \
  --target weqrom/dist/Weqrom.apk \
  --output-dir weqrom/dist/builder \
  --zip weqrom/dist/Weqrom-Builder.zip
```

Входной SHA-256 и сертификат основы закреплены; другой файл отклоняется. Скрипт сохраняет сжатые байты неизменённых ZIP-записей, что позволяет получить небольшой COPY/INSERT-пакет. Закрытый ключ хранится только в `/workspace/.weqrom-signing` (переопределение `--signing-dir`); сохраните его приватную резервную копию для будущих обновлений. Ключ/пароль не входят в Git, APK или ZIP-сборщик.

```sh
python3 -m unittest discover -s weqrom/tests -v
```

Отдельный тест настоящего APK: задайте `WEQROM_ACTUAL_SOURCE` и `WEQROM_ACTUAL_TARGET`, затем выполните `python3 weqrom/tests/test_web_builder.py ActualBrowserTests`. Тесты используют локальные данные/loopback; нужен Playwright с Chromium. Фикстуры не подтверждают запуск Android-приложения.
