# Chits Market

Android-маркет с локальными APK, удалённым каталогом, панелью администратора и настоящим локальным ИИ на llama.cpp. Интерфейс на русском, с анимациями и поддержкой системного уменьшения движения.

## Установка на телефон

1. Установите `dist/Chits-Market.apk`. Нужен **Android 8.0+ с 64-битной ARM64-системой** и актуальным Android System WebView.
2. «Орбита» (45 игр) и «Прорыв» уже включены. Откройте «Загрузки» → «Установить». Android предложит разрешить Chits Market установку приложений; после разрешения вернитесь в маркет и подтвердите системную установку. Интернет не нужен.
3. Новые приложения скачиваются с подключённого сервера. После сохранения APK их тоже можно устанавливать офлайн. Можно импортировать APK через файловый менеджер телефона.
4. Удаление сохранённого APK освобождает место, но не удаляет установленное приложение. Встроенные игры можно снова скопировать без Интернета.

Маркет не обходит подтверждения Android, проверки подписи и совместимости APK. Сервер не выполняет антивирусную проверку; администратор отвечает за публикуемые приложения.

## Администратор и удалённые загрузки

Никнейм: **Leon_Salimov**. В исходном облачном окружении аккаунт создан с указанным пользователем паролем; в базе сохраняется только PBKDF2-хеш. Пароля нет в APK и исходниках. Данные сервера находятся вне репозитория: `/workspace/.chits-market-data`.

Для удалённой работы разместите сервер на постоянно работающем хосте с HTTPS. [Инструкция сервера](server/README.md) содержит команды и пример reverse proxy. При переносе создайте администратора с желаемым паролем через безопасный ввод stdin либо перенесите приватный каталог данных по защищённому каналу. Каталог данных и ключи подписи **не входят** в архив исходников.

После размещения укажите HTTPS-адрес в «Настройки» → «Подключение». Администратор может войти и загрузить APK с телефона или открыть этот же адрес в браузере компьютера. Токен входа живёт только в памяти интерфейса; после перезапуска требуется повторный вход. Скачанные APK остаются на телефоне, даже если приложение убрали с сервера.

Сервер в этой задаче проверен локально; публичный хостинг и домен не создавались.

## Офлайн-ИИ

В APK включён реальный ARM64-движок llama.cpp, а не ответы по ключевым словам. Модель **Qwen2.5 0.5B Instruct Q4_K_M** скачивается отдельно с официального репозитория Qwen на Hugging Face (приблизительно 400–500 МБ). Для телефона с 8 ГБ ОЗУ это разумный небольшой вариант.

Откройте «Помощник» → «Скачать модель один раз». Для этой операции нужен Интернет и свободное место. Загрузчик закрепляет ревизию официального репозитория и сверяет размер и SHA-256 модели до использования. Также можно импортировать совместимый GGUF с устройства. После подготовки модели чат работает без подключения и не отправляет переписку на сервер. Готовность загрузчика зависит от доступности Hugging Face на телефоне.

Это небольшая модель, существенно слабее ChatGPT: она может ошибаться, отвечать медленно и плохо справляться со сложными вопросами. Контекст ограничен 2048 токенами, ответ — 256 токенами. Текущая версия отправляет модели один текущий вопрос; история видна в интерфейсе и хранится локально, но не подмешивается автоматически в следующие запросы. Кнопки быстрой справки помечены отдельно и не выдают шаблонный текст за ИИ.

Нативный движок собран и проверен по архитектуре, JNI и выравниванию 16 КиБ. **Реальная генерация и установка на Android-устройстве в облачной среде не проверялись.** Модель не включена в APK и не скачивалась в облачную среду.

## Сборка и разработка

Проект не требует Gradle и внешних JS-зависимостей. Нужны Linux x86_64, Python 3.12+, Java 21, `curl`, `unzip`, `zip`, `openssl`, `keytool`. Сценарий скачивает официальные Android SDK 35 / Build Tools 35.0.0 и Eclipse ECJ с закреплёнными контрольными суммами.

```sh
cd /workspace/hhhhhg/chits-market
bash tools/build-apk.sh
```

Выход: `dist/Chits-Market.apk`. SDK и зависимости находятся вне проекта в `/workspace/.chits-tools`. Путь можно задать через `CHITS_TOOLS_DIR`.

Ключ обновлений хранится отдельно в `/workspace/.chits-signing` (переопределение `CHITS_SIGNING_DIR`). Сохраните его приватную резервную копию: другой ключ не сможет обновить установленный APK поверх прежнего. Новый ключ создаётся только если его ещё нет. Никогда не добавляйте этот каталог в Git или публичный архив.

Предсобранная библиотека находится в `app/src/main/jniLibs/arm64-v8a/`. После изменений в C++ пересоберите её:

```sh
bash ai-native/build.sh
bash tools/build-apk.sh
```

Подробности и лицензия llama.cpp — в [ai-native](ai-native/README.md). В APK включено уведомление о лицензии. Существующие APK игр в родительском каталоге не изменяются.

## Проверки

```sh
python3 -m unittest discover -s server -v
python3 tests/test_ui.py
```

Вторая команда требует Python Playwright и Chromium; они уже доступны в подготовленной облачной среде. Проверки используют временный loopback-сервер; при ограничениях песочницы потребуется разрешение локальных сокетов. Они проверяют браузерный интерфейс, реальный API и имитацию Android-моста, но не заменяют установку на телефон.
